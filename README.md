# Inkwell

Open-source handwriting notes and PDF / EPUB reader. All features free — no paywall, no locked notebooks, no VIP tier.


## What it does

- Unlimited notebooks and folders
- Handwriting with real stylus pressure, tilt and twist (perfect-freehand)
- Calligraphy pen, tables, shapes, text boxes, images, layers
- PDF import and annotation, EPUB reader with reflow
- Text-select highlights, annotations, bookmarks, outline, thumbnails
- Page management: rotate, delete, reorder, extract, merge, split
- Read-aloud with named accents and male/female voices
- Dictionary and Wikipedia lookup on long-press
- Floating drafting board (infinite canvas overlay per page)
- Focus timer, split screen, bidirectional links, handwriting-to-text
- Audio-synced notes, export and backup

## Design

The interface follows the editorial ink direction in `DESIGN.md`: warm paper, dense ink, one vermilion accent, Newsreader for display and reading, Instrument Sans for the interface. Icons are Tabler Icons (MIT), inlined as a small SVG sprite so the page loads only the glyphs it uses.

## Status

In active development. The web preview is the current build vehicle; the Android app is the main goal, with a website version alongside it. Phone first, tablet layouts throughout, PC later.
